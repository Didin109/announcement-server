Solusi Jam 20:00 Otomatis via GitHub Actions

Website statis butuh server untuk kirim jam 20:00 saat browser ditutup. Gunakan fitur GitHub gratis ini!

Agar pesan otomatis terkirim **setiap jam 20:00 WIB secara otomatis di cloud (tanpa harus buka browser)**, buat file workflow di repository GitHub Anda:

Cara Pemasangan:

  1. Buka Repository GitHub tempat Anda meng-upload website ini.
  2. Klik Add file > Create new file.
  3. Beri nama file: .github/workflows/discord_bot.yml
  4. Paste isi kodingan YAML di atas lalu klik Commit changes.
  5. Selesai! GitHub server akan mengirim pesan ini secara otomatis **setiap jam 20:00 WIB** selamanya gratis tanpa perlu buka browser!
