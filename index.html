Panduan Upload ke GitHub Pages

Jadikan bot web scheduler ini online 24/7 gratis

1

Simpan File Website

Simpan kode halaman ini dengan nama file index.html.

2

Buat Repository Baru di GitHub

Buka github.com/new, beri nama repository (misal: discord-bot-scheduler), lalu buat repository Public.

3

Upload File

Klik Upload an existing file, tarik file index.html, lalu klik tombol Commit changes.

4

Aktifkan GitHub Pages

Masuk ke menu Settings > Pages. Pada bagian Build and deployment, pilih Source: Deploy from a branch, pilih branch main / root, lalu Save.

Tips Pro: Setelah di-host, cukup biarkan tab browser ini terbuka di latar belakang atau perangkat kedua untuk menjalankan scheduler.
